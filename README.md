# Play Tennis Decision Tree Classifier

This repository contains a Jupyter Notebook demonstrating how to train and evaluate a **Decision Tree Classifier** model on the synthetic `Play Tennis` dataset using Python and `scikit-learn`.

---

## 📌 Project Overview

The objective of this project is to build a classification model that predicts whether conditions are suitable to play tennis based on various weather parameters.

### Features in Dataset:
* **Outlook**: Weather condition (e.g., *Sunny*, *Overcast*, *Rain*)
* **Temperature**: Outdoor temperature level (e.g., *Hot*, *Mild*, *Cool*)
* **Humidity**: Air humidity level (e.g., *High*, *Normal*)
* **Wind**: Wind speed condition (e.g., *Weak*, *Strong*)
* **Play Tennis (Target)**: Binary decision (*Yes* / *No*)
